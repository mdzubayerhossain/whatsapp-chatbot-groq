
## 🧠 WhatsApp AI Chatbot – Intelligent, Context-Aware Conversations

The **WhatsApp AI Chatbot** is a robust, production-ready solution designed to enhance customer service and engagement through intelligent, context-aware conversations. Built on top of the **NestJS framework**, the chatbot leverages state-of-the-art technologies including **Groq**, **Stability AI**, and **Redis**, ensuring a powerful and scalable communication platform for businesses.

---

### 🚀 Key Features

- **🧠 Groq Integration (GPT-4o):**  
  Empowers the chatbot with natural language understanding and generation, enabling smart, fluid, and human-like conversations.

- **🎨 Text-to-Image Generation (Stability AI):**  
  Converts textual prompts into high-quality images using **Stable Diffusion** by Stability AI, adding a visual edge to conversations.

- **🧠 Context Persistence with Redis:**  
  Utilizes **Upstash Redis** to maintain conversation history and state, ensuring meaningful and context-aware responses.

- **⚙️ Built with NestJS:**  
  Structured and maintainable backend architecture using the scalable **NestJS** framework for clean code and future-proof design.

- **📦 Production-Ready:**  
  Designed for real-world deployments with focus on performance, reliability, security, and scalability.

### 🛠️ Getting Started

#### 1. **Install Node.js**
Download and install the latest version from: [https://nodejs.org](https://nodejs.org)

#### 2. **Install Dependencies**
```bash
npm install
```

#### 3. **Configure Environment Variables**
Set up environment variables for:
- OpenAI / Groq API key
- Stability AI API token
- Redis credentials (Upstash/ioredis)
- WhatsApp Cloud API details

#### 4. **Run the Chatbot**

- **Development Mode**
```bash
npm run start:dev
```

- **Debug Mode**
```bash
npm run start:debug
```

- **Production Mode**
```bash
npm run start:prod
```
